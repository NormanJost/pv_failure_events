# Publish this folder with GitHub Pages

1. Create or open the GitHub repository that will host the explorer.
2. Put the **contents of this folder** at the repository root. `index.html`, `events.js`, `assets/`, and `data/` must be at that top level.
3. In **Settings** -> **Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, and save.
4. Share the URL GitHub displays after deployment.

Do not put this folder inside another repository subfolder; GitHub Pages needs `index.html` at the selected root.
